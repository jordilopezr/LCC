# D5 — Cutover: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que el motor nativo sea el defecto, que el usuario pueda elegir el de gcloud desde Ajustes, y que LCC deje de invocar la auth de gcloud sin mutilar esa escotilla.

**Architecture:** Un módulo `native/src/engine_pref.rs` posee `engine.json` y resuelve el motor con precedencia `LCC_AUTH_ENGINE` > fichero > nativo; `oauth::auth_engine()` pasa a consultarlo. Se borran las cuatro invocaciones de auth de gcloud y en su lugar la UI muestra el comando que el usuario debe ejecutar. Todo lo que *lee* gcloud —listar, cambiar, tokens, ADC— se conserva.

**Tech Stack:** Rust (serde_json, anyhow, tracing), flutter_rust_bridge 2.11.1, Flutter/Dart con Riverpod y SharedPreferences.

**Spec:** [`docs/superpowers/specs/2026-08-24-d5-cutover-design.md`](../specs/2026-08-24-d5-cutover-design.md)

## Global Constraints

- **Se conservan `list_gcloud_accounts_async`, `switch_gcloud_account_async`, `get_gcloud_account`, el token por `print-access-token`, `token_from_adc_refresh`, la verja del ADC y `is_gcloud_installed`/`is_gcloud_authenticated`.** El criterio es: **lo que invoca la auth de gcloud se va; lo que solo la lee se queda.** Borrar de más mutila la escotilla que la decisión del 2026-08-21 conserva a propósito.
- **Precedencia del motor, de mayor a menor:** `LCC_AUTH_ENGINE`, luego `engine.json`, luego nativo. El env gana siempre: es la escotilla de diagnóstico y el QA en entorno hostil depende de ella.
- **Paridad i18n obligatoria:** toda clave nueva va en `lib/l10n/app_en.arb` **y** `lib/l10n/app_es.arb`, con los mismos placeholders, seguida de `flutter gen-l10n`. Una clave que falta en un idioma es un crash en tiempo de ejecución, no un error de compilación.
- Secretos jamás en logs ni en mensajes de error.
- **Prohibido `#[allow(dead_code)]`** y cualquier otro silenciado de lints.
- **NO ejecutar `dart format`** en ningún momento.
- Rama `27H1-Preview`. Los commits de código **no** llevan trailer `Co-Authored-By`; el del checklist de QA sí.

```rust
//! Which auth engine LCC uses, and where that choice is stored.
//!
//! Rust owns the file so the answer is available from the very first call —
//! before any UI exists. A setter that Dart had to call at startup would leave
//! a window in which early calls silently used the default, and "sometimes it
//! starts on the wrong engine" is a bug that costs days to chase.

use anyhow::{anyhow, Context, Result};
use serde::{Deserialize, Serialize};
use std::path::PathBuf;

use crate::oauth::AuthEngine;

#[derive(Serialize, Deserialize, Default)]
struct EnginePref {
    auth_engine: Option<String>,
}

fn pref_path() -> Option<PathBuf> {
    Some(
        crate::app_dirs::migrated_app_dir(dirs::data_local_dir()?)
            .join("engine.json"),
    )
}

/// Resolve the engine from the two sources, most significant first.
///
/// The environment variable wins outright: it is the diagnostic escape hatch,
/// and the hostile-environment QA launches the app with it. An unrecognised
/// value at either level falls through rather than deciding, so a corrupt file
/// cannot silently move a user onto another engine.
pub(crate) fn resolve(env: Option<&str>, file: Option<&str>) -> AuthEngine {
    for candidate in [env, file].into_iter().flatten() {
        match candidate {
            "native" => return AuthEngine::Native,
            "gcloud" => return AuthEngine::Gcloud,
            _ => continue,
        }
    }
    AuthEngine::Native
}

/// The stored choice, or `None` when the user has never made one.
pub fn stored_engine() -> Option<String> {
    let path = pref_path()?;
    let raw = std::fs::read_to_string(&path).ok()?;
    // A corrupt file is not a crash: it means "no preference".
    let pref: EnginePref = serde_json::from_str(&raw).ok()?;
    pref.auth_engine
}

/// Persist the user's choice.
pub fn set_stored_engine(engine: &str) -> Result<()> {
    if engine != "native" && engine != "gcloud" {
        return Err(anyhow!("Unknown auth engine: {}", engine));
    }
    let path = pref_path().ok_or_else(|| anyhow!("Cannot determine the data directory"))?;
    if let Some(parent) = path.parent() {
        std::fs::create_dir_all(parent).context("Failed to create the data directory")?;
    }
    let json = serde_json::to_string(&EnginePref { auth_engine: Some(engine.to_string()) })
        .context("Failed to serialize the engine preference")?;
    // Write through a temp file: a half-written engine.json would read as "no
    // preference" on the next launch and silently move the user's engine.
    let tmp = path.with_extension("json.tmp");
    std::fs::write(&tmp, json).context("Failed to write the engine preference")?;
    std::fs::rename(&tmp, &path).context("Failed to replace the engine preference")?;
    tracing::info!(engine, "Stored the auth engine preference");
    Ok(())
}
```

```dart
/// Show the "native sign-in is now the default" notice, once, and only to
/// someone who arrived at the new default without asking for it.
///
/// Both conditions matter. The flag stops it repeating; `storedAuthEngine() ==
/// null` stops it reaching someone who already picked an engine by hand —
/// nothing changed for them, so there is nothing to explain.
Future<void> maybeShowEngineChangeNotice(BuildContext context, WidgetRef ref) async {
  final storage = StorageService();
  if (storage.getEngineChangeNoticeSeen()) return;
  if (await storedAuthEngine() != null) return;
  if (!context.mounted) return;

  // Marked BEFORE showing: if the app is closed with the dialog open, not
  // showing it again beats showing it every launch.
  await storage.setEngineChangeNoticeSeen();

  final l10n = AppLocalizations.of(context);
  await showDialog<void>(
    context: context,
    builder: (dialogContext) => AlertDialog(
      title: Text(l10n.engineNoticeTitle),
      content: SingleChildScrollView(child: Text(l10n.engineNoticeBody)),
      actions: [
        TextButton(
          onPressed: () {
            Navigator.pop(dialogContext);
            showSettingsDialog(context);
          },
          child: Text(l10n.engineNoticeOpenSettings),
        ),
        FilledButton(
          onPressed: () => Navigator.pop(dialogContext),
          child: Text(l10n.engineNoticeGotIt),
        ),
      ],
    ),
  );
}
```

```rust
/// How a gcloud check reports, given the engine in use.
///
/// Under the native engine a missing gcloud is irrelevant, not a failure —
/// the user this release targets is precisely the one without it. Under the
/// gcloud engine it is exactly as decisive as it always was.
fn gcloud_check_status(engine: crate::oauth::AuthEngine, present: bool) -> DoctorCheckStatus {
    match engine {
        crate::oauth::AuthEngine::Native => DoctorCheckStatus::Skipped,
        crate::oauth::AuthEngine::Gcloud if present => DoctorCheckStatus::Pass,
        crate::oauth::AuthEngine::Gcloud => DoctorCheckStatus::Fail,
    }
}
```

`"Not applicable: the auth engine is native"` — un `Skipped` sin motivo deja al
usuario sin saber si la comprobación falló o no se hizo.
