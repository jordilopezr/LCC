# i18n (EN+ES) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Localize the LCC Flutter UI to English (template) and Spanish using the official `gen-l10n` pipeline, with a system-default + manual-override language selector in Settings.

**Architecture:** Standard Flutter `gen-l10n`: `.arb` files in `lib/l10n/` generate `AppLocalizations`, accessed via `AppLocalizations.of(context)`. A `LocaleNotifier` (Riverpod, SharedPreferences-persisted, modeled on the existing `ThemeModeNotifier`) drives `MaterialApp.locale`. Strings migrate incrementally, one file per task/commit, on branch `26H2U2`.

**Tech Stack:** Flutter (flutter_localizations SDK, intl), Riverpod 3.x Notifier, SharedPreferences.

**Spec:** `docs/superpowers/specs/2026-07-16-i18n-design.md` (approved).

## Global Constraints

- Branch: `26H2U2`. One commit per task; app must compile (`flutter analyze` → 0 errors, `flutter gen-l10n` succeeds) at every commit.
- Locales: `en` (template `app_en.arb`) and `es` (`app_es.arb`). Every key added to one file MUST be added to the other in the same commit.
- Key naming: camelCase, module prefix (`settingsTitle`, `sftpUploadFailed`); shared strings use `common` prefix (`commonCancel`).
- DO NOT translate: product/tech names (LCC, GCP, SSH, SFTP, VNC, RDP, gcloud…), shell commands, paths, URLs, SharedPreferences keys, log/debug-only strings, `debugPrint`/`print` output.
- Rust-side error messages and deep-provider technical messages stay in English this phase (spec §4).
- `AppLocalizations` import in widgets: `import 'package:flutter_gen/gen_l10n/app_localizations.dart';` — use local `final l10n = AppLocalizations.of(context);` at the top of `build`/callback.
- Placeholders use typed .arb placeholders, never string concatenation.

## Standard Migration Recipe (referenced by Tasks 4–17)

Every migration task follows these steps. "The file" = the task's target file.

1. **Enumerate**: read the file; list every user-visible literal (Text, SnackBar, tooltip, labelText, hintText, title, dialog copy, button labels). Skip the DO-NOT-TRANSLATE categories.
2. **Add keys** to `lib/l10n/app_en.arb` (English text, `description` metadata when the key name alone is ambiguous) and `lib/l10n/app_es.arb` (Spanish translation). Reuse existing `common*` keys instead of adding duplicates.
3. **Replace literals** in the file with `l10n.<key>`. Widgets that were `const` because of literal strings lose `const` as needed. Interpolations become placeholder calls.

   Example (from `account_management_dialog.dart`):
   ```dart
   // before
   SnackBar(content: Text('Switched to ${account.account}'))
   // app_en.arb
   "accountSwitchedTo": "Switched to {account}",
   "@accountSwitchedTo": {"placeholders": {"account": {"type": "String"}}}
   // app_es.arb
   "accountSwitchedTo": "Cambiado a {account}",
   // after
   SnackBar(content: Text(l10n.accountSwitchedTo(account.account)))
   ```
4. **Verify**: run
   ```bash
   flutter gen-l10n   # Expected: exits 0, no untranslated-messages warning
   flutter analyze    # Expected: 0 errors (infos OK)
   ```
5. **Spot-check in Spanish**: `flutter run -d linux` briefly OR rely on the widget smoke test: `flutter test test/l10n_smoke_test.dart` → PASS.
6. **Commit**:
   ```bash
   git add lib/l10n/ <the file>
   git commit -m "i18n: migrate <file basename>"
   ```

- [ ] **Step 2: Implement `LocaleNotifier`** in `settings_provider.dart` (same pattern as `ThemeModeNotifier`):
```dart
// ==========================================
// APP LOCALE (i18n)
// ==========================================

final localeProvider = NotifierProvider<LocaleNotifier, Locale?>(
  LocaleNotifier.new,
);

/// App locale override. `null` means follow the system locale.
class LocaleNotifier extends Notifier<Locale?> {
  @override
  Locale? build() {
    _loadLocale();
    return null; // Default: follow system locale
  }

  Future<void> _loadLocale() async {
    final prefs = await SharedPreferences.getInstance();
    final code = prefs.getString('app_locale');
    if (code != null && code != 'system') {
      state = Locale(code);
    }
  }

  Future<void> setLocale(Locale? locale) async {
    state = locale;
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString('app_locale', locale?.languageCode ?? 'system');
  }
}
```
Add `import 'package:flutter/material.dart';` if not already imported (for `Locale`).
